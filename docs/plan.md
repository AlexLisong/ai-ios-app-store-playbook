# Playbook scope and acceptance

This repository captures reusable, anonymized lessons from two iOS release workflows.

Acceptance:

- English and Simplified Chinese entry points, with concrete commands and prompts.
- Clear build/upload/submission/approval distinctions and verified-evidence boundaries.
- Coverage of native audio, on-device and optional Azure privacy, signing, device handoffs, icons/screenshots, listing, support hosting and troubleshooting.
- Generic templates and read-only local validation helpers; no production deployment helper.
- No personal account/contact data, identifiers, production infrastructure, private paths, credentials, recordings or account screenshots.
- Local links and JSON validated; script behavior checked with temporary synthetic fixtures.
- Independent content/sanitization review before initial publication.

The repository does not include original application code, source release logs, archives, real release receipts or screenshots. An identifiable app's live submission status belongs in that app's private operational record.
