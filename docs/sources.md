# Official references / 官方参考

Use primary documentation before each release. These links support the decisions in the playbook; UI labels, SDK deadlines and service behavior can change. Lessons were collected in September 2026. All 16 listed external URLs were checked in September 2026 for successful HTTP responses and expected page titles. That link check is not a complete reread of every specification. This repository's automated checks validate local links and file structure, not ongoing correctness or availability of external websites.

## Apple

- [App Store Connect Help](https://developer.apple.com/help/app-store-connect/) — current app, version, build, review and distribution workflows.
- [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) — completeness, accurate metadata, privacy, third-party AI transfer and other review requirements.
- [App privacy details](https://developer.apple.com/app-store/app-privacy-details/) — collection definition, linked data, purposes, optional-disclosure criteria and content classification.
- [Privacy manifest files](https://developer.apple.com/documentation/bundleresources/privacy-manifest-files) — collected data and required-reason APIs in the bundle.
- [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) — accepted screenshot sizes and display requirements.
- [Upload builds](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds/) — supported transfer methods and processing.
- [Submit for review](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/overview-of-submitting-for-review/) — review submissions and required completion.
- [Cloud-managed certificates](https://developer.apple.com/help/account/certificates/cloud-managed-certificates/) — supported managed signing and role requirements.
- [Upcoming requirements](https://developer.apple.com/news/upcoming-requirements/) — SDK/build policy changes.
- [Apple Developer Program](https://developer.apple.com/programs/) — current membership and program details.
- [Speech framework](https://developer.apple.com/documentation/speech) — speech API capabilities and availability.
- [Foundation Models](https://developer.apple.com/documentation/foundationmodels) — on-device model integration and availability handling.
- [Translation framework](https://developer.apple.com/documentation/translation) — native translation integration.
- [AVFAudio](https://developer.apple.com/documentation/avfaudio) — audio sessions, engine, files and synthesis.

## Microsoft

- [Data, privacy and security for Models sold by Azure](https://learn.microsoft.com/en-us/azure/foundry/responsible-ai/openai/data-privacy) — provider processing, retention, geography and deployment distinctions.
- [Abuse monitoring](https://learn.microsoft.com/en-us/azure/foundry/openai/concepts/abuse-monitoring) — automated/human monitoring and customer-specific arrangements.

No generic provider page proves that a particular customer's endpoint, model deployment, API version, retention arrangement or billing configuration has been tested. Keep that evidence in the actual app's private release record.
